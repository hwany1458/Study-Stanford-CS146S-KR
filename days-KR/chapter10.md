## 2. 새롭게 등장하는 AI 프로그래밍 패러다임

### 에이전트 주도 개발
- AI 에이전트가 자율적으로 개발 작업을 완수
- "직접 하는 것"에서 "관리하는 것"으로 전환
- 서브에이전트: 에이전트가 에이전트를 관리

### 자연어 프로그래밍
- 요구사항을 자연어로 설명해 코드를 생성
- 프롬프트는 제안일 뿐
- 프로그래밍 진입 장벽이 낮아짐

### 자동화된 소프트웨어 공학
- 자가 치유 시스템
- 지속적 학습
- 엔드투엔드 워크플로

### 기술 동향

| 동향 | 설명 | 영향 |
|------|------|------|
| 에이전트 주도 개발 | AI 에이전트가 자율적으로 작업 완수 | 효율의 대폭 향상 |
| 자연어 프로그래밍 | 요구사항을 설명하면 코드 생성 | 프로그래밍 진입 장벽 하락 |
| 자가 치유 시스템 | 시스템이 문제를 자동으로 감지하고 수정 | 운영 부담 감소 |
| 지속적 학습 | AI가 코드베이스로부터 계속 학습 | 지식 축적 가속 |

## 3. 산업 동향과 예측

### AI 코딩 도구의 세 시대

| 세대 | 도구 | 효율 향상 | 특징 |
|------|------|-----------|------|
| 1 | GitHub Copilot | 약 10% | 코드 완성, 로컬 개발 |
| 2 | AI IDE (Cursor) | 약 20% | 단일 작업 완수, 클라우드 협업 |
| 3 | AI 에이전트 (Devin) | 6-12배 | 다중 작업 병렬, 클라우드 비동기 |

### 개발자 도구의 도입 속도

> "우리는 역사상 가장 빠른 수준의 새로운 개발 도구 도입을 목격하고 있다"

역사상 가장 빠른 개발자 도구 도입:
- 에이전트 자율성을 활용하기 위해 UX/UI가 빠르게 진화
- 개별 솔루션에서 올인원 플랫폼으로 통합되는 흐름

### AI 개발자 제품의 7가지 원칙

1. **Start with what developers know** - 개발자가 이미 아는 것에서 시작하라
2. **Configuration flexibility** - 설정의 유연성
3. **Focus on developer ergonomics** - 개발자의 사용 편의성에 집중하라
4. **Chat as a first-class citizen** - 채팅을 1급 시민으로
5. **MCP Integration** - MCP 통합
6. **Rapid feedback loops** - 빠른 피드백 루프
7. **Agent Workflows** - 에이전트 워크플로

### 핵심 통찰

> "여러분은 AI에게 대체되지 않습니다. AI를 쓸 줄 아는 유능한 엔지니어에게 대체될 것입니다."

- LLM은 딱 여러분 수준만큼만 잘한다 (좋은 컨텍스트가 좋은 코드로 이어진다)
- 여러분이 자신의 코드베이스를 이해하지 못한다면, LLM도 이해하지 못한다
- 이 강의는 "바이브 코딩" 강의가 아니라 "Human-agent engineering" 강의다
